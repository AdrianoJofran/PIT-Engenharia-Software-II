Plano de Testes

Objetivo:
Verificar o funcionamento das principais funcionalidades do sistema.

Teste 1 - Cadastro de Máquina
Resultado Esperado:
Cadastrar uma máquina com sucesso.

Teste 2 - Cadastro de Técnico
Resultado Esperado:
Cadastrar um técnico com sucesso.

Teste 3 - Cadastro de Manutenção
Resultado Esperado:
Registrar uma ordem de serviço corretamente.

Teste 4 - Consulta de Manutenções
Resultado Esperado:
Exibir as manutenções registradas.

Teste 5 - Atualização de Status
Resultado Esperado:
Alterar o status da manutenção para "Em andamento" ou "Concluída".
