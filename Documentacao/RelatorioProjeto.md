# Sistema de Controle de Manutenção Industrial

## Introdução

Este projeto foi desenvolvido para a disciplina Projeto Integrador Transdisciplinar em Engenharia de Software II.

## Objetivo

Desenvolver um sistema para auxiliar no controle de manutenções industriais através do cadastro de máquinas, técnicos e ordens de serviço.

## Justificativa

A manutenção adequada dos equipamentos é fundamental para evitar paradas não planejadas e melhorar a eficiência operacional.

## Requisitos Funcionais

- Cadastrar máquinas.
- Cadastrar técnicos.
- Registrar manutenções.
- Consultar histórico de manutenções.
- Atualizar status das manutenções.

## Requisitos Não Funcionais

- Interface simples e intuitiva.
- Sistema acessível por navegador.
- Armazenamento em banco de dados.
- Facilidade de manutenção.

## Tecnologias Utilizadas

- HTML
- Python
- Flask
- SQL

## Conclusão

O projeto atende aos requisitos propostos para controle básico de manutenções industriais e demonstra a aplicação dos conceitos estudados durante a disciplina.
