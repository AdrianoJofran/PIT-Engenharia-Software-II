# Caso de Uso

## Atores

- Administrador
- Técnico

## Casos de Uso

### UC01 - Cadastrar Máquina
O usuário informa os dados da máquina e salva o cadastro.

### UC02 - Cadastrar Técnico
O usuário informa os dados do técnico e salva o cadastro.

### UC03 - Abrir Ordem de Serviço
O usuário cria uma solicitação de manutenção para uma máquina.

### UC04 - Consultar Manutenções
O usuário visualiza as manutenções registradas.

### UC05 - Atualizar Status
O usuário altera o status da manutenção para:
- Aberta
- Em andamento
- Concluída
