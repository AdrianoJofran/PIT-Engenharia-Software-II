Documentação do Projeto Integrador de Engenharia de Software II.

Título: Sistema de Controle de Manutenção Industrial

Objetivo: Desenvolver um sistema web para controle e acompanhamento das manutenções realizadas em máquinas industriais, permitindo o cadastro de equipamentos, técnicos responsáveis e ordens de serviço.

Justificativa: O controle das atividades de manutenção é fundamental para garantir a disponibilidade dos equipamentos, reduzir paradas não planejadas e melhorar a gestão das informações relacionadas às máquinas industriais.

Funcionalidades do Sistema

1. Cadastro de Máquinas
Permite registrar as máquinas da empresa.

2. Cadastro de Técnicos
Permite registrar os técnicos responsáveis pelas manutenções.

3. Cadastro de Ordens de Serviço
Permite abrir uma ordem de serviço para manutenção de uma máquina.

4. Consulta de Manutenções
Permite visualizar o histórico de manutenções realizadas.

5. Atualização de Status
Permite alterar o status da manutenção para:
- Aberta
- Em andamento
- Concluída

Requisitos Funcionais

RF01 - Cadastrar máquinas.
RF02 - Consultar máquinas cadastradas.
RF03 - Cadastrar técnicos.
RF04 - Abrir ordem de serviço.
RF05 - Consultar histórico de manutenção.
RF06 - Alterar status da manutenção.

Requisitos Não Funcionais

RNF01 - Sistema acessível via navegador.
RNF02 - Interface simples e intuitiva.
RNF03 - Armazenamento dos dados em banco de dados.
RNF04 - Disponibilidade para acesso local.
